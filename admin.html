⚙️ Administrivia

LLM Use Policy

Students can use LLMs for checking spelling and grammar and as they would a search engine (e.g., finding related work), but they cannot be used to produce any deliverable for this course. That includes reading papers, writing reading responses, making presentations, analyzing data, and building systems. This is a course about identifying new ways systems fail and cause harm and how to solve these problems. LLMs won't offer any new insight here; they are trained on existing work, and this is a problem existing work still hasn't solved. If you are unsure of whether or not you can use an LLM for a particular task in this course, best to just ask the instructor. Failure to follow these policies will be considered an academic violation.
